# GNOME Settings

## Multitasking

- App Switching
  - Include apps from the current workspace only

## Keyboard

### View and Customize Shortcuts

**Navigation**

- `Move window one workspace to the left`: Shift+Super+A
- `Move window one workspace to the right`: Shift+Super+D
- `Switch applications`: Disabled
- `Switch to workspace on the left`: Super+A
- `Switch to workspace on the right`: Super+D
- `Switch windows`: Alt+Tab

**Windows**

- `Close window`: Shift+Super+Q

**Custom Shortcuts**

- `Clipboard`: Ctrl+Alt+V
- `Launcher`: Ctrl+Space
- `Terminal`: Super+Return

## Privacy & Security

### Screen Lock

- Blank Screen Delay: 15 minutes
- Automatic Screen Lock: Enable
- Automatic Screen Lock Delay: 5 minutes
- Lock Screen Notifications: Enable
