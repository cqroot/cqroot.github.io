## 1. 占位符（verbs）

| 占位符 | 说明                                                                                                                                    |
| :----: | :-------------------------------------------------------------------------------------------------------------------------------------- |
|  `%v`  | 值的默认格式                                                                                                                            |
| `%+v`  | 类似 `%v`，但结构体会带字段名                                                                                                           |
| `%#v`  | 值的 Go 语法表示（带类型信息）；浮点的 `±Inf` / `NaN` 打印为 `±Inf` / `NaN`                                                             |
|  `%T`  | 值的类型（Go 语法表示，注意是大写 T）                                                                                                   |
|  `%%`  | 一个字面量百分号（无参数）                                                                                                              |
|  `%t`  | 布尔值：`true` 或 `false`                                                                                                               |
|  `%b`  | 整数：二进制；浮点数：无小数点的二进制科学计数法（指数为 2 的幂，如 `-123456p-78`）                                                     |
|  `%c`  | 对应的 Unicode 字符                                                                                                                     |
|  `%d`  | 十进制整数                                                                                                                              |
|  `%o`  | 八进制整数                                                                                                                              |
|  `%O`  | 八进制整数，带 `0o` 前缀                                                                                                                |
|  `%q`  | rune / 整数：单引号包裹的字符字面量；string / `[]byte`：双引号包裹的字符串（均按 Go 语法安全转义）                                      |
|  `%x`  | 整数：十六进制（小写）；浮点数：十六进制浮点（如 `-0x1.23abcp+20`）；string / `[]byte`：base16 编码（每字节两个字符）；指针：按整数处理 |
|  `%X`  | 同 `%x`，但字母为大写                                                                                                                   |
|  `%U`  | Unicode 格式：`U+1234`（等价于 `U+%04X`）；`%#U` 会附带可打印字符，如 `U+0078 'x'`                                                      |
|  `%e`  | 科学计数法（小写，如 `1.23e+04`），默认精度 6                                                                                           |
|  `%E`  | 科学计数法（大写，如 `1.23E+04`）                                                                                                       |
|  `%f`  | 小数格式（无指数部分），默认精度 6                                                                                                      |
|  `%F`  | 同 `%f`                                                                                                                                 |
|  `%g`  | 根据数值大小自动选择 `%e` 或 `%f`；精度表示**有效数字上限**（尾随零会被去掉）                                                           |
|  `%G`  | 根据数值大小自动选择 `%E` 或 `%F`                                                                                                       |
|  `%s`  | 字符串或字节切片；也适用于实现了 `error` / `fmt.Stringer` 的类型（会调用其 `Error()` / `String()`）                                     |
|  `%p`  | 指针地址（base16，带 `0x` 前缀）；对 slice 是第 0 个元素的地址；`%#p` 去掉 `0x` 前缀                                                    |
|  `%w`  | 仅用于 `fmt.Errorf`，包装错误以便后续 `errors.Is` / `errors.As` / `errors.Unwrap`；Go 1.20 起可包装多个错误                             |

## 2. 标志（flags）

|    标志     | 说明                                                                                                                                                                             | 示例              |
| :---------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------- |
|     `+`     | 数值总是带符号；`%+q` 保证输出为纯 ASCII                                                                                                                                         | `%+d` → `+42`     |
|     `-`     | 左对齐，右侧补空格                                                                                                                                                               | `%-6d` → `42    ` |
|     `#`     | 替代格式：`%#b` 加 `0b`、`%#o` 加 `0`、`%#x`/`%#X` 加 `0x`/`0X`、`%#p` 去掉 `0x`；浮点总是输出小数点、`%#g`/`%#G` 保留尾零；`%#q` 可用时用反引号原始字符串；`%#U` 附带可打印字符 | `%#x` → `0x2a`    |
| ` `（空格） | 数值的符号位留空；`% x`/`% X` 在字节之间加空格                                                                                                                                   | `% d` → ` 42`     |
|     `0`     | 用前导零而非空格填充（对数值会把填充移到符号之后）                                                                                                                               | `%06d` → `000042` |

## 3. 宽度与精度

- **宽度**：紧跟在 `%` 之后的可选十进制数，如 `%6d`，表示输出的最小宽度，不足时默认用空格补齐。
- **精度**：在宽度之后用 `.` 加十进制数，如 `%.2f`、`%.3s`；单独的 `.` 表示精度为 0（如 `%9.f`）。
- **组合**：`%9.2f`、`%06.2f` 等。
- 对字符串、字节切片和字节数组，精度限制的是**输入长度**（会截断），而不是输出的宽度；正常情况下按 rune 计算，用 `%x` / `%X` 时按字节计算。
- 对浮点数，`%e` / `%f` 的默认精度是 6，`%g` / `%G` 的精度是有效数字上限；`%g` 默认使用能唯一标识该值的最少位数。
- 宽度和精度都可以用 `*` 从参数动态获取，此时**紧邻的实参**必须是 `int`：

```go
fmt.Printf("%*d\n", 5, 42)   // "   42"
fmt.Printf("%.*f\n", 2, 3.14159) // "3.14"
```

- 也可以用 `[n]` 显式指定参数索引：

```go
fmt.Printf("%[2]d %[1]d\n", 1, 2) // "2 1"
```

## 4. `%v` 的默认格式

| 类型              | 默认格式               |
| :---------------- | :--------------------- |
| `bool`            | `%t`                   |
| 整数              | `%d`                   |
| 浮点 / 复数       | `%g`                   |
| `string`          | `%s`                   |
| `chan` / 指针     | `%p`                   |
| `struct`          | `{field0 field1 ...}`  |
| `array` / `slice` | `[elem0 elem1 ...]`    |
| `map`             | `map[key1:value1 ...]` |
| 指向上述的指针    | `&{}`、`&[]`、`&map[]` |

## 5. 接口与特殊类型

- 无论使用哪种占位符，**接口值打印的都是其底层具体值**，而不是接口本身：

```go
var i any = 23
fmt.Printf("%v\n", i) // 23
```

- 打印时会依次考虑操作数实现的接口：`Formatter`、`GoStringer`（配合 `%#v`）、`error`（调用 `Error()`）、`Stringer`（调用 `String()`）。因此自定义类型可以通过实现这些接口来控制输出。
- `[]byte` 在使用 `%s` / `%q` / `%x` / `%X` 时会被**整体当作字符串或字节处理**；而 `%v` 会输出每个字节的数字，例如 `[104 101 108 108 111]`。
